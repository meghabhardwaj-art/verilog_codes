# Verilog Digital Design

## Overview

This repository contains a collection of Verilog HDL codes
implemented to practice and demonstrate fundamental digital
design concepts.

## Contents

The repository includes Verilog implementations of:

- Combinational logic circuits
- Sequential logic circuits
- Finite State Machine (FSM) based designs
- Counters and registers
- Arithmetic and logic circuits
- Memory-based designs
- Digital system design examples

The codes cover both basic and intermediate RTL design concepts
using Verilog HDL.

## Tools

- Verilog HDL
- Vivado
